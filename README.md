# Textimage

[![Pipeline](https://git.drupalcode.org/project/textimage/badges/5.0.x/pipeline.svg)](https://git.drupalcode.org/project/textimage/-/pipelines)

Adds text-to-image functionality using GD2 and FreeType, enabling users to
create images on the fly for use as theme objects, headings, or countless
other possibilities.

It integrates with the Image Effects module's "Text overlay" effect: the
default text specified in the image effect configuration gets replaced by
text values that come from field values, or from other sources via the
Textimage API. It also provides field display formatters for Text and Image
fields, an API to generate Textimage images programmatically, and tokens to
retrieve the URI/URL of generated Textimage images.

For a full description of the module, visit the
[project page](https://www.drupal.org/project/textimage).

Submit bug reports and feature suggestions, or track changes in the
[issue queue](https://www.drupal.org/project/issues/textimage).

## Requirements

This module requires the following:

- GD2 and FreeType libraries
- [Image Effects](https://www.drupal.org/project/image_effects)

## Installation

1. Download and install via Composer:

   ```bash
   composer require drupal/textimage
   ```

1. Enable the module:

   ```bash
   drush en textimage
   ```

## Configuration

Configure via Manage > Configuration > Media > Textimage:

- **Default image file extension** - the default extension of images
  produced by Textimage. Can be overridden by image style effects that
  specify a format conversion, such as "Convert". Does not affect image
  derivatives created by Drupal core's Image module.
- **URL generation** - whether to enable direct URL generation, and the
  string used to separate text elements pushed to separate "Text overlay"
  effects during generation.
- **Maintenance** - whether Textimage logs debug messages of its
  operations. The "Cleanup Textimage" button removes all images and image
  metadata generated by Textimage (this also flushes all image derivatives
  generated by Drupal core's Image module).

## Features

- Field display formatters for Text and Image fields, driven by "Text
  overlay" image effects
- A Textimage API to generate Textimage images programmatically, with a
  caching mechanism keyed on the input image style/effects and overlaid text
- Tokens to retrieve the URI/URL of generated Textimage images
- Direct URL generation for on-the-fly image creation, gated by the
  "generate textimage url derivatives" permission

## Using the API

```php
try {
  $bubbleable_metadata = new BubbleableMetadata();
  $textimage = \Drupal::service('textimage.factory')->get($bubbleable_metadata)
    ->setStyle(ImageStyle::load($style_name))
    ->process([$text_strings])
    ->buildImage();
  $variables['textimage_image'] = [
    '#theme' => 'textimage_formatter',
    '#uri' => $textimage->getUri(),
    '#width' => $textimage->getWidth(),
    '#height' => $textimage->getHeight(),
    '#title' => t('textimage'),
    '#alt' => t('Textimage image.'),
  ];
  $textimage->getBubbleableMetadata()->applyTo($variables['textimage_image']);
}
catch (TextimageException $e) {
  \Drupal::service('textimage.logger')->error('Failed to build a Textimage image.');
}
```

See [`src/TextimageInterface.php`](src/TextimageInterface.php) and
[`src/TextimageFactoryInterface.php`](src/TextimageFactoryInterface.php) for
the full API surface.
